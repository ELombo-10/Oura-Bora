# Oura-Bora

Personal health dashboard that connects to the Oura Ring API (OAuth2) to display
the account owner's own sleep, readiness, activity, and heart-rate data.

**For personal use only.** Operated by and for a single individual. Not a commercial
product and not offered to other users.

Published via GitHub Pages — see `index.html`, `privacy-policy.html`, `terms.html`,
and `redirect.html` (OAuth2 callback).
