Personal Health Project

Lombardino Health Dashboard

⚠️ For personal use only — this application is operated by and for a single individual (the account owner) to view their own Oura Ring data. It is not a commercial product, not offered to or used by any other people, and accesses no one else’s data.

A private dashboard that connects to my Oura Ring to view my own sleep, readiness, activity, and heart-rate trends in one place.

What this app does

This application uses the Oura API (OAuth2) to read the account owner's own biometric data — sleep, readiness, activity, workout, and heart-rate metrics — and display them in a personal dashboard. It is for individual, non-commercial use.

Data & privacy

The app only accesses data the user explicitly authorizes via Oura's consent screen. Data is used solely to display the user's own metrics and is never sold or shared. See the Privacy Policy for details.
